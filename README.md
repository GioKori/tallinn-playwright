# Tallinn Delivery UI - Playwright Test Suite

This project contains automated UI tests for the Tallinn Delivery application using Playwright, Faker.js, and environment variables managed via dotenv.

## 🚀 Features

- Generates random usernames and passwords using Faker.js
- Loads application URL from environment variable `APP_URL`
- Includes Playwright tests for login functionality
- Supports GitHub Actions CI workflow
